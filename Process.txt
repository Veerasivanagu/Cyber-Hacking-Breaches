========================================================
1. PROJECT OVERVIEW
========================================================

CyberHackingBreaches is an AI-based cyber hacking breach detection system developed
to identify security threats and unauthorized access in real-time. The system allows
users and administrators to upload datasets, train machine learning
models, and detect cyber-attacks based on network and system data.

The system provides the following modules:

1. User Login System
2. Dataset Upload
3. Model Training
4. Manual Threat Prediction
5. Breach Detection Result
6. Analytics and Charts
7. Performance Analysis

========================================================
2. MAIN OBJECTIVE
========================================================

The main objective of Cyberhackingbreaches is to detect cyber hacking
breaches using machine learning techniques and provide accurate
results to enhance system security.

7. HOW TO RUN THE PROJECT
========================================================

STEP 1:
Open the project folder.

STEP 2:
Ensure Python is installed.

STEP 3:
Install required libraries:

pip install flask flask-sqlalchemy pandas numpy scikit-learn joblib matplotlib

STEP 4:
Run the application:

python app.py

STEP 5:
Open browser and go to:

http://127.0.0.1:5000/

========================================================
8. HOW TO USE THE PROJECT
========================================================

STEP 1: Open Home Page
- Launch the project in browser.

STEP 2: Login
- Enter username and password.

STEP 3: Upload Dataset
- Upload CSV file containing cyber-attack data.

STEP 4: Train Model
- Click "Train Model" button.
- System trains model using dataset.

STEP 5: Manual Prediction
- Enter system/network details manually.

STEP 6: Submit Input
- Click predict button.

STEP 7: View Result
- System displays whether activity is:
  Attack or Normal.

STEP 8: View Analytics
- Check charts and performance results.

STEP 9: Logout
- Exit the system safely.
